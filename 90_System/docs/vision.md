# lua_Agent Vision

`lua_Agent` is a customizable Agent OS for people who use many AI tools but need one continuous project operator.

The first goal is not to automate every connected service. The first goal is to make work durable:

- commands become projects and tasks
- tasks always keep a next action
- progress is recorded as checkpoints
- Codex, Claude, and other AI tools receive clear work instructions
- Obsidian and Notion preserve memory and operating state

The first flagship agent is `lua_Project_Agent`.

It helps move projects forward from idea to research, planning, implementation, review, documentation, and the next step.

The long-term goal is for other people to define their own purpose-specific agents, such as:

- `RealEstate_Agent`
- `Marketing_Agent`
- `Trading_Agent`
- `Monitoring_Agent`
- `Education_Agent`
- `Research_Agent`

Each custom agent should reuse the same core: projects, tasks, checkpoints, tool routing, approval gates, memory, and documentation.
